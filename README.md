# PredictX

**آزمایشگاه پژوهشی برای کشف و ارزیابی رفتارهای تکرارشونده بازار**

PredictX در فاز نخست روی داده‌های XAUUSD متمرکز است. هدف، کشف، ثبت، اندازه‌گیری و اعتبارسنجی رفتارهای آماری و توالی‌های زمانی است؛ نه تولید سیگنال معاملاتی یا فرض سودآوری.

## اصول بنیادین
- تفکیک تعریف رفتار، وقوع رفتار و پیامد مشاهده‌شده.
- استفاده از اطلاعات قابل‌دسترس در زمان تصمیم و جلوگیری از نشت آینده.
- ثبت منشأ داده، نسخه تعریف، پارامترها و نتایج برای بازتولیدپذیری.
- جداسازی داده‌های کشف، اعتبارسنجی و آزمون خارج از نمونه.
- گزارش عدم‌قطعیت، وابستگی نمونه‌ها و محدودیت‌های کیفیت داده.
- عدم ادعای اعتبار یا سودآوری بدون آزمون مستقل و هزینه‌های اجرایی واقع‌بینانه.

## وضعیت پروژه
در حال طراحی پژوهشی؛ هنوز هیچ الگوی بازار تأیید یا استراتژی معاملاتی پیاده‌سازی نشده است.

- منبع داده و منطقه زمانی: تعیین نشده؛ باید در قرارداد ورودی ثبت شوند.
- تایم‌فریم‌ها و افق‌ها: پارامترهای نسخه‌بندی‌شده آزمایش.

هرگز توکن، کلید API، اطلاعات حساب کارگزاری یا داده حساس را در مخزن ثبت نکنید. داده خام بازار تا تعیین مجوز منبع و سیاست نگهداری وارد Git نمی‌شود.
