# PredictX

**آزمایشگاه پژوهشی برای کشف و ارزیابی رفتارهای تکرارشونده بازار**

PredictX در فاز نخست روی داده‌های XAUUSD متمرکز است. هدف پروژه، کشف، ثبت، اندازه‌گیری و اعتبارسنجی الگوهای آماری و توالی‌های زمانی است؛ نه تولید سیگنال معاملاتی یا فرض سودآوری.

## اصول بنیادین

- تفکیک تعریف رفتار، وقوع رفتار و پیامد مشاهده‌شده.
- استفاده از داده‌های در دسترس در زمان تصمیم و جلوگیری از نشت اطلاعات آینده.
- ثبت منشأ داده، نسخه تعریف، پارامترها و نتایج برای بازتولیدپذیری.
- جداسازی داده‌های کشف، اعتبارسنجی و آزمون خارج از نمونه.
- گزارش عدم‌قطعیت، وابستگی نمونه‌ها و محدودیت‌های کیفیت داده.
- عدم ادعای اعتبار یا سودآوری بدون آزمون مستقل و هزینه‌های اجرایی واقع‌بینانه.

## وضعیت پروژه

در حال طراحی پژوهشی؛ هنوز هیچ الگوی بازار تأیید یا استراتژی معاملاتی پیاده‌سازی نشده است.

## دامنه نسخه اولیه

- دارایی آغازین: XAUUSD
- منبع داده و منطقه زمانی: هنوز تعیین نشده‌اند؛ باید در قرارداد ورودی داده ثبت شوند.
- تایم‌فریم‌ها، افق‌ها و روش‌های آماری: پارامترهای آزمایش و نسخه‌بندی‌شده خواهند بود.

## امنیت

هرگز توکن، کلید API، فایل حساب کارگزاری یا داده حساس را در مخزن ثبت نکنید. داده‌های خام بازار نیز تا تعیین مجوز منبع و سیاست نگهداری وارد مخزن Git نمی‌شوند.
