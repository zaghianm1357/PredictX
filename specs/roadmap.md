| 2 | PX-ARCH-001 | معماری ماژولار | مرز ماژول‌ها، جریان داده، قرارداد API و تصمیم فناوری | بعدی |

## دروازه‌های کیفیت
- هر نتیجه باید dataset/version و experiment protocol داشته باشد.
- هیچ تغییر schema بدون migration و تست سازگاری انجام نمی‌شود.
- داده خام و credential در Git commit نمی‌شوند.
- معیارهای پذیرش و تست‌های ضد look-ahead پیش از انتشار اجرا می‌شوند.
